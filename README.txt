THE VELVET OVEN BAKERY — ADVANCED WEBSITE

Open index.html in your browser for a preview.

To deploy on Vercel:
1. Extract the ZIP.
2. Upload these files to a GitHub repository (files at repository root).
3. In Vercel: Add New > Project > Import Git Repository > Deploy.
   Framework preset: Other. No build command required.

Includes: homepage, 8 individual recipe pages, searchable/filterable recipes, browser-saved favourites, story page, responsive navigation.

Note: The photos and Google fonts require an Internet connection. Recipe favourites are saved locally in the visitor browser. There is no checkout or real ordering backend.
